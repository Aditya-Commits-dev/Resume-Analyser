# 🤖 AI Resume Analyser

**Live Project : https://ats-insight.netlify.app/**

An AI-powered Resume Analyser that evaluates resumes, generates an ATS (Applicant Tracking System) score, provides personalized feedback, identifies strengths and weaknesses, and suggests improvements to help candidates optimize their resumes for recruiters.

---

## 📌 Features

- 📄 Upload Resume (PDF)
- 🤖 AI-powered Resume Analysis
- 📊 ATS Compatibility Score
- 💼 Skills Detection
- 📝 Resume Summary
- ⚡ Strengths & Weaknesses Analysis
- 💡 Personalized Improvement Suggestions
- 🎯 Recruiter-Friendly Recommendations
- 📱 Responsive User Interface
- 🔒 Secure API Integration

## 🖥️ Usage

1. Open the application.
2. Upload your resume in PDF format.
3. Wait for AI analysis.
4. View your ATS Score.
5. Read strengths and weaknesses.
6. Improve your resume using AI suggestions.

---

## 📊 ATS Score

The application estimates how well a resume aligns with Applicant Tracking Systems by evaluating:

- Resume Structure
- Skills Match
- Keywords
- Formatting
- Professional Summary
- Experience
- Education
- Technical Skills
- Overall Readability
